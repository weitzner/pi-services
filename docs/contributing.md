# Contributing

Thanks for your interest in Pi Services.

Bug reports, feature requests, documentation improvements, and pull requests are all welcome.

---

## Before Opening a Pull Request

- Keep changes focused and easy to review.
- Update documentation when behavior changes.
- Test changes with `docker compose up -d`.
- Verify all containers start successfully.

---

## Reporting Issues

When reporting a problem, please include:

- Raspberry Pi model
- Operating system and version
- Docker version (`docker version`)
- Docker Compose version (`docker compose version`)
- Relevant logs (`docker compose logs`)
- Steps to reproduce the issue

---

## Design Philosophy

Pi Services values:

- Privacy-first defaults
- Simple, transparent configuration
- Reproducible deployments
- Minimal external dependencies
- Clear documentation over clever automation
